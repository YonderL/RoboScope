# Reproducibility contract

## What can be reproduced immediately

All public figures regenerate from `results/libero_spatial/episodes.csv`, `provenance.json`, `dp_train_history.json` and `act_learning_curve.csv`. The reader rejects duplicate/missing task-init pairs and mixed checkpoint hashes before aggregation. Published per-task counts are 50. Every group has exactly 500 rows.

`provenance.json` stores checkpoint identity, gradient step, original shard config/episode-file hashes, and raw latency samples. `protocol.json` stores BDDL/init hashes, image convention, controller parameters and trajectory split membership. Original absolute paths are not exported. Training checkpoints, raw demos, simulator assets and videos remain local; no hosted checkpoint URLs are claimed.

The historical ACT learning curve CSV is an audited three-seed aggregate from the original run. Unlike the 3,500-row matched study, its full underlying 24,000-rollout archive is not bundled in this first source release. Its error bars and denominators must remain separately labeled.

## What “same initial state” guarantees

It controls the benchmark state and episode seed, not every floating-point operation. Batch shape, environment completion order, BF16 kernels, library versions and physical GPU selection can change actions slightly and amplify differences through contact dynamics. Per-episode DP random generators prevent sampling noise from being shared across slots, but do not guarantee cross-batch bitwise equivalence.

Two evaluations should agree on: dataset/split, task identity, init hash/index, camera orientation, action units/scaling, controller, settling actions, horizon, success predicate, inference settings, checkpoint hash, AMP mode, batch scheduler and dependency versions. Do not compare a 20-episode historical result to a 50-episode result as if the denominator were unchanged.

## Selection and uncertainty

- One seed in the matched study: no cross-seed std, no stable method ranking claim.
- Three ACT ablation seeds: mean and sample std across those seeds.
- Paired bootstrap: task-stratified resampling of 50 initial states per task, 10,000 replicates, seed2026. Conditional on already-trained weights; not seed uncertainty or a proof of equivalence.
- DP final was chosen for a follow-up after inspecting best's results. Checkpoint and parameter sweeps should use a separate development rollout set in future work.
- Minimum validation noise MSE and highest SR are different criteria. Store final and intermediates if investigating this relationship.

## Archival behavior

New runs snapshot the package source and `pip freeze`. Resume rejects source/config/manifest changes. Evaluation has a separate run directory and checks checkpoint hashes. A partial last JSONL line may be discarded during resume; missing episodes must be completed before reporting. Current schema versions and imported upstream versions remain part of the experiment contract.

The reorganized package is an engineering migration. Published scores were not regenerated by the refactor. See `validation.md` for bounded checks and their limits.
